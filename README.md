# PROYECTO AQUACHILE - REACT

## Instrucciones de Lanzamiento

Para inicializar el proyecto:
- Tener node.js instalado
- Abrir terminal
- Navegar a la carpeta correspondiente - ("cd .../proyectoAquaChile")
- Ejecutar comando: npm run dev

Analiza este proyecto: La idea es que lo desarrollemos poco a poco. Lo primero que debemos priorizar es pasar de usar datos simulados con mockData a usar una base de datos real...
